## A. 资产格式侧（按优先级）

### A1. 装备类部件的时间轴与身体不同步 —— 高优先

**现象**：把朝向 0 的部件表叠起来时，`Spr#967`（斗笠）在 `frame 0/16` 浮在角色上方，
到 `frame 48` 才落回头上。

**已确认**：`Spr` 组合表里武器/帽子这类部件引用的帧包块和身体部件同属一个朝向块，
但它们的帧号推进节奏不同。

**要查**：装备部件的帧号是否有一条独立时间轴，或者由"手持/头部挂点"驱动。
真答案应该能解释为什么同一 `frame` 下斗笠和头的相对位置会变。

**影响**：重制版里"武器/帽子跟着手走"需要额外规则，越早定越好。

### A2. `.fol` 容器 —— 已解决（2026-11-07）

格式完全解开，`tools/rekit/fol.py` 可列目录与解包，三份全部成功。
见 [research/08-fol-container.md](../research/08-fol-container.md)。

要点：`u32 count`（最高位 = 是否加密）+ `count × 0x88` 目录（名字 / 偏移 / 大小）+
负载 + 末尾种子表；目录按 `j³·9 + seed[i]` 三阶差分还原，
负载按 `99·i² + seed[i]` 二阶差分还原。

顺带发现两件大事：
- `mb.fol` 其实是**开发期的数据目录**：`Role.txt`、`Skill.ini`(330 KB)、`player/`（含 `.xls`）、
  `trigger/`（126 个触发器脚本）、`BLD_*.Mdl`（建筑模型，头 `leyibld1.50`）全在里面
- `slr.fol` 里有 **`SprRole.h`**：35 KB 的 `#define SPR_ROLE_<角色>_<部位>_<动作>_<变体> <下标>`，
  等于 `Spr` 库的**官方命名表** —— 部件语义不明的问题可以直接靠它查

**遗留**：`.Mdl` / `.MAP` / `.PLI` 的内部结构还没解析（见 A7）。

## C. 管线与工程

### C1. 批量导出 + manifest

目标是给重制版一份 `动作 → 帧 → 层[{图片, 偏移}]` 的清单，直接能被 Godot 消费。

### C2. 音频 / 视频转码

`sy/*.sy` 是 RIFF WAV、`dhp/*.dhp` 是 MPEG-1 PS，都只是封装改名的普通格式，
可以直接批量转 OGG / 现代 MP4。
