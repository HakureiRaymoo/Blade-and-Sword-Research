# `Role.txt` 列画像

> 生成方式：`py tools/rekit/table_profile.py --file <Role.txt> --out docs/04-role-columns.md`
> 表格下面是人工整理出的解读。

## 先说结论

1. **8 列是彻底空的**（永远不用）：`手动ID`、`R*G*B`、`平时思想`、`攻击思想`、
   `性格3`、`性格4`、`移动技`、`抗技能`。
2. **3 列是常量**：`动作`(=1)、`挨打返技`(=203)、`移动属性`(=1) —— 没有调节价值。
3. **真正能调的是 10 列左右**：`大小`、`脚数`、`平时速度`、`组`、`方向与头`、
   `受伤效果`、`移动效果`、`光影效果`、以及动作/序列那几列。
4. `死亡块` / `防守块*盲目块` / `自由序列` / `先后序列` **不是数字，是身体部位代码**
   （`TK` 躯干、`HD` 头、`LA`/`RA` 左右臂、`LH`/`RH` 左右手、`CA` 腿）——
   和 `SprRole.h` 里那套部位缩写是同一套。

## 已确认语义的列

| 列 | 证据 |
| --- | --- |
| `平时速度` | 实测：8→14 迈步变慢、8→4 步频变急。是**每步的节拍长度**，越小越快 |
| `组` | `10001` 全是可玩角色（剑客/女主角/道士/力士/女英雄/薛燕影），`3` 全是怪（食人僵尸/山猫精…），`101` 全是友好 NPC（铁蛋/行囊/翠娟）。即**阵营** |
| `脚数` | `2` 人形、`4` 野兽（大蝙蝠/僵尸犬/地狱猎犬）、`0` 飞行或无脚（鹰/蛇/魔鹰王）、空值 是道具（酒坛/墓碑/桶） |
| `大小` | 只有 6 档（16/32/48/49/64/96），大部分 32，装货的"行囊"是 64 —— 像是**尺寸分级**（碰撞/选框/缩放） |
| `自由序列` / `先后序列` | 只有怪有值，且就是部位代码序列（如 `RH` / `CA*TK*HD`）——驱动的应该是**怪物攻击的肢体顺序** |
| `受伤效果` / `移动效果` / `光影效果` | 取值很少且成档（23/60/65…、0/88、0/1），是**效果 ID** |

| `预读动画` | 18 个动作编号 | 加一个动作，看是否被预载 |
